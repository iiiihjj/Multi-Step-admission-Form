# Multi-Step-admission-Form
 Project Overview

The Multi-Step Form is a responsive web application built using HTML, CSS, and JavaScript. It allows users to complete a registration form in multiple steps instead of entering all information on a single page.

The project focuses on improving the user experience through step-by-step navigation, form validation, a dynamic progress bar, and automatic saving of entered information.

✨ Features

Step-by-Step Navigation: Complete the registration form in multiple steps.

Dynamic Progress Bar: Track progress as you move through the form.

Form Validation: Validate required fields before proceeding to the next step.

Previous and Next Buttons: Navigate between form steps.

Final Summary: Review all entered information before submission.

Autosave: Automatically save form data in browser localStorage.

Data Restoration: Restore saved information after refreshing the page.

Smooth Transitions: Add visual animations when switching between steps.

Responsive Design: Support desktop and mobile screen sizes.

Success Message: Display a confirmation message after submission.

🚀 How to Run the Project

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open index.html in your web browser, or use the Live Server extension.

Enter your personal and additional information.

Navigate through the steps using the Previous and Next buttons.

Review the final summary and click Submit.

📋 Form Steps

Step 1: Personal Information

Full Name

Email Address

Phone Number

Step 2: Additional Information

City

Country

Occupation

Step 3: Review and Submit

Review all entered information.

Submit the completed form.

Display a success message.

💾 Autosave Functionality

The project uses the browser's localStorage to save entered form data automatically. If the user refreshes the page, the previously saved information is restored.

Saved form data is removed from localStorage after successful submission.
